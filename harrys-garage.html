About HTML Garage

HTML Garage is a programme-agnostic HTML tool security certification service. Any Accenture team that produces standalone HTML tools may use it.

Certification confirms the tool has completed a baseline security hardening checklist (C1–C8). It is not a full InfoSec audit or penetration test. The primary danger is not the roadworthiness of the vehicle. It is how it is driven.

All registered tools are visible to all users within this tile. Tools must be re-certified every 90 days. The CMMYY suffix on the filename (e.g. _C0127) tells you when certification lapses.

What this certification is — and what it isn't

This process applies a standardised baseline security check to your HTML tool. It confirms the tool meets a defined set of mechanical requirements before it runs on Accenture or client systems.

It is not a full security audit or penetration test. Certification does not mean the tool is safe to handle sensitive data. It means the known checklist items have been addressed. The primary risk is not the tool. It is what data you run through it and where.

The following checks are applied (C1–C9):

  • C1 — No external scripts, stylesheets or fonts loaded from remote URLs
  • C2 — Content Security Policy meta tag present
  • C3 — DOM output sanitised (no unescaped innerHTML)
  • C4 — No dynamic code execution (eval, new Function)
  • C5 — Input validation present where required
  • C6 — CSV export formula injection guard (where applicable)
  • C7 — No undeclared use of localStorage / sessionStorage / cookies
  • C8 — Accenture Security Review audit comment block present in source
  • C9 — Certification footer with countdown timer present in source

The certified file will contain a discreet status footer showing the certification expiry date. This footer links to the certification record on Accenture's internal registry for audit purposes.

Important: You will be asked to declare whether this tool is intended to ingest or process client data. If it is, additional care applies to C3 and C5.
