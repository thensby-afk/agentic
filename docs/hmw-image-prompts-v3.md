# HTML Garage — Image Generation Prompts v3
**Version:** 3.0 | **Date:** 2026-10-26
**Status:** Self-contained — each prompt is ready to paste directly into an image generator with no other context required.
**Change from v2:** Tony (chief mechanic) added as second recurring character. Licence plates may now show letters/numbers.

---

## How to use

Each prompt is a complete, standalone block. Copy the text inside the code fence and paste it directly into your generator (ChatGPT image generation, Midjourney, etc.).

**Midjourney users:** append the `--ar` flag shown under each image. Append `--style raw` to reduce aesthetic bias. Use `--sref` with the accepted IMG-01 as a style reference for all subsequent images.

**If a generation adds UI text or labels (other than licence plates):** re-run with the note "No text, signs, or labels of any kind are visible except on vehicle licence plates — any other signage is blurred or stylised to illegibility."

## Recurring characters (embedded in every prompt)

**Harry Williams (proprietor / customer liaison):** Stocky British man, late 50s. Dark navy Fred Perry polo shirt, khaki chinos, worn leather shoes. Grey-flecked short hair. Reading glasses occasionally worn or perched. Expression defaults to sceptical patience — never broadly smiling, at most a slight reluctant grin. Harry manages the paperwork and most customer interaction.

**Tony (chief mechanic):** Short, slight Italian man, late 50s. Blue mechanic's overalls, slightly worn and oil-stained. Grey hair, kept short. Looks like he has had a slightly harder existence than Harry — more weathered, more tired, more concentrated. Tony rarely stops working. Where Harry watches and considers, Tony does.

## Production checklist

Before accepting any image for use in the site:

- [ ] No legible text, signs, or labels anywhere — except vehicle licence plates
- [ ] Harry and Tony are both recognisable and consistent across the set (costume, build, hair)
- [ ] Harry: navy polo, khaki chinos, leather shoes — never overalls
- [ ] Tony: blue mechanic's overalls, grey hair, slightly worn look — never polo shirt
- [ ] Pixel art style consistent (not photorealistic, not smooth vector)
- [ ] Aspect ratio matches target (16:7 for IMG-01; 16:5 for IMG-02–07)
- [ ] Colour temperature matches scene (warm interior / cool exterior / blend at threshold)
- [ ] Harry's and Tony's hands and faces look correct (common AI failure point — regenerate if distorted)
- [ ] Garage interior is consistent across scenes (same wall colour, key cabinet visible in office shots)
